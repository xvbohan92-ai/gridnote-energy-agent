接入你的小时负荷数据
在本地终端执行，下列命令会用校验后的 CSV 替换当前数据库。
energy-agent import-csv /path/to/load.csv --source "你的数据来源" --replace
必需列：timestamp_utc、region、load_mw；可选列：forecast_mw。也支持 PJM 导出的 datetime_beginning_utc、load_area、mw。仅接受整点 UTC 小时数据；预测缺失请留空。

分析工作流
任务与范围 → SQL 计划 → 只读校验和预编译 → 执行 → 独立 Python 指标核验 → 有限纠错 → 结果与依据。
运行模式
规则演示：提取 Top-K、时间粒度和日类型参数，支持有限任务，无 API 调用。OpenAI：模型生成查询计划，使用相同的数据库约束与已支持任务的数值核验；开放式问题会标注语义未覆盖。工具 Agent：模型选择查结构、查询、指标计算、绘图和结束工具，读取返回结果后决定下一步；只有选定本次运行的有效证据才发布答案。模型调用有次数上限，首页预览不调用模型。切换方式见项目 README。
边界与评测
首版每次分析一个区域，最多 366 天、500 行结果。异常只是探索性筛查，无法解释因果。内置 26 个合成用例，比较单次生成、基础纠错和领域核验三个流程；另列 4 类显式故障注入诊断。历史不足不当作正常。新增 EIA-930 真实负荷导入和 36 道契约检查；这些规则检查不代表真实模型准确率。本机已完成 Qwen3-4B 的 QLoRA 训练与 SQL 组件评测，详见上方固定实验记录。
